Submit answers

POST /api/quizzes/{quizId}/submit

POST

For SINGLE_CHOICE, the answer is the chosen option's id (see "Quiz detail" above). For TRUE_FALSE use "True"/"False". Matching is case-insensitive for ONE_LINE and TRUE_FALSE.

Runs entirely in your browser and calls the API directly — nothing is sent anywhere else. If requests fail immediately, confirm the backend is running and the Base URL above is correct.
